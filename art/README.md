# Art

`icon-source.png` is the app icon source (1264×1264, generated with Canva's AI and chosen on 30/10/2026). The launcher
icon is built from it: the central 964 px are cut out (clear of the rounded corners), padded with the same black
(#0D0D0D) to 1740 px so the pages are 54 dp tall in the 108 dp adaptive icon, and resized to each density
(`app/src/main/res/mipmap-*/ic_launcher_foreground.png`). The themed (monochrome) icon is a vector outline in
`app/src/main/res/drawable/ic_launcher_monochrome.xml`.
